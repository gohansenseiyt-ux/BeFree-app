Sécurité Security

Non signé, mais transparent

Unsigned, but transparent

SHA-256 ee7aa690b94bccebe70683b1b31ff04f49e2f0440f891c4ca61cdc6e48b7a3ce

Pourquoi Windows affiche un avertissement ? BeFree n'est pas encore signé par un certificat d'éditeur (ça coûte cher pour un projet solo). Windows affiche donc "Éditeur inconnu" par précaution — clique sur Plus d'infos puis Exécuter quand même. Le code est vérifiable sur GitHub et le hash ci-dessus te permet de confirmer que le fichier n'a pas été modifié.

Why does Windows show a warning? BeFree isn't signed with a publisher certificate yet (expensive for a solo project). Windows shows "Unknown publisher" as a precaution — click More info then Run anyway. The hash above lets you confirm the file hasn't been tampered with.
